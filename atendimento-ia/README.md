# Atendimento com IA

**Estado:** planejado. Ainda sem código.

## O que é

A preencher quando o projeto for construído.

## Qual problema resolve

Um agente de IA integrado à aplicação responde perguntas usando uma base de respostas cadastradas. Quando a confiança é baixa, a conversa vai para um atendente humano, e a resposta aprovada por ele entra na base. O modelo é local (Ollama), sem custo por uso.

## Limitações conhecidas

A preencher ao construir. Hipóteses iniciais: o modelo pode inventar respostas, e o sistema melhora pela base de respostas, não por novo treinamento do modelo.
