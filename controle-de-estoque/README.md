## Qual problema resolve

Há 1 unidade em estoque e dois clientes pedem ao mesmo tempo. Só um pode comprar. O README final traz o teste que reproduz esse cenário e compara duas técnicas: atualização condicional atômica e bloqueio de linha.

O escopo previsto inclui um painel com login e MFA (TOTP).

## Limitações conhecidas
